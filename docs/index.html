POSTGRESQL DB UPGRADE TOOL

Migration command generator

Generate a Bash command for an offline database migration or backup. The generator does not run commands or transmit your input. Do not enter passwords or private key contents.

Repository and full documentation

Database
Storage and backup encryption

Vendor-specific TDE is not supported. For filesystem encryption, verify that the source, working directory and final destination share the required encryption policy. The generator does not validate Docker images or your host filesystem.

Execution

Advanced opt-in: disable automated redeployment and ensure these containers cannot write to the database or migration workspace. Direct database mounts and filesystem-root mounts remain blocked.

Command

Before execution

  1. Stop the source application and all writers with docker compose down (without -v). Disable automated redeployment.
  2. Run the generated command from the migration repository on the local Docker host as a non-root user with Docker access. Database file ownership is detected automatically; do not change the original permissions. The database root must be writable for upgrades.
  3. On successful migration, update only the original PostgreSQL major image tag and restart. On backup-only, leave the tag unchanged.
  4. Verify data and retain the old cluster until rollback is no longer needed.
